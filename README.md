# Moniepoint-Strategic-Case-Study
## The Problem
Moniepoint's Sales Network has 95 State Coordinators(SC) and 7 Regional Managers(RM) overseeing 11,000 Business Relationship Managers(BRM) across Nigeria. This creates an unmanageable span of control each SC is indirectly responsible for over 100 BRMs, far exceeding the recognised management best practice of 8-25. Noticeable effects of these includes: coordination bottlenecks, limited coaching, and a network that cannot effectively scale.
